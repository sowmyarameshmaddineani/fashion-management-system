# 🛍️ VOGUE | Full-Stack Django E-Commerce Fashion System

A professional, high-performance e-commerce web application engineered for Indian fashion retail (traditional and modern wear)[cite: 7]. Built as a portfolio project to streamline product cataloging, secure user authentication, shopping carts, checkout workflows, and admin order tracking[cite: 7].

---

## 🚀 Tech Stack
- **Backend**: Python, Django, SQLite, Django ORM, Django Admin[cite: 7]
- **Frontend**: HTML5, CSS3, Bootstrap 5, Bootstrap Icons, Responsive UI Components[cite: 7]
- **Assets & Data**: Unsplash High-Resolution CDN Integration & Custom Python Seeding Scripts (`seed_data.py`)[cite: 7]

---

## ✨ Key Features
- **Curated Multi-Category Catalog**: Precisely structured collections spanning **Men**, **Women**, **Kids**, and **Accessories** featuring authentic apparel and accessories[cite: 7].
- **Advanced Search & Filtering**: Instant category switching and keyword search capabilities[cite: 7].
- **Secure User Authentication**: Complete user registration, login, logout, and role-based session protection[cite: 7].
- **Interactive Shopping Bag & Cart**: Real-time quantity tracking, item removal, and live total cost calculation[cite: 7].
- **Saved Shipping Addresses & Checkout**: Multi-address management per user with a streamlined end-to-end order placement flow[cite: 7].
- **Order History & Success Tracking**: Dedicated user order history dashboard and order success confirmations with timestamps and statuses[cite: 7].
- **Admin Management Dashboard**: Fully integrated Django Admin backend configured with custom lists, filters, and search fields to track all customer orders and inventory[cite: 7].
