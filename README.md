# 🛍️ VOGUE | Full-Stack Django E-Commerce Fashion System

A fully responsive, feature-rich E-Commerce Web Application built with **Python**, **Django**, and **Bootstrap 5**, styled with a modern Myntra-like UI. Designed to handle end-to-end shopping workflows from catalog browsing to order management and admin tracking.

---

## 🚀 Key Features

- **Multi-Category Dynamic Catalog**: Curated collections spanning *Men, Women, Kids, and Accessories*, populated via a custom database seeding script.
- **Advanced Search & Filtering**: Instant keyword search and category-based filtering.
- **Secure User Authentication**: Complete user registration, login, logout, and role-based session protection.
- **Shopping Bag & Cart Management**: Real-time quantity tracking, item removal, and live total cost calculation.
- **Saved Shipping Addresses & Checkout**: Multi-address management per user with streamlined order placement.
- **Order History & Success Tracking**: Dedicated user order history dashboard with timestamping and status badges.
- **Admin Management Dashboard**: Fully integrated Django Admin backend for tracking orders, managing inventory, and monitoring user activity.

---

## 🛠️ Tech Stack

- **Backend**: Python, Django (Views, Models, ORM, Authentication, Admin)
- **Database**: SQLite (Development)
- **Frontend**: HTML5, CSS3, Bootstrap 5, Bootstrap Icons, JavaScript
- **Images & Assets**: Unsplash High-Resolution CDN Integration
