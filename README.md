# 🛍️ Vogue - Python Full-Stack Fashion Management System

A professional, high-performance e-commerce web application engineered for Indian fashion retail (North & South Indian traditional and modern wear). Built as a portfolio project to streamline product cataloging, user authentication, inventory management, and order processing.

---

## 🚀 Tech Stack
* **Backend**: Python, Django, SQLite
* **Frontend**: HTML5, CSS3, Bootstrap 5, Responsive UI Components
* **Data Management**: Custom Python Seeding Scripts (`seed_data.py`) ensuring 1:1 visual-to-data integrity across categories.

---

## ✨ Key Features
* **Curated Multi-Category Catalog**: Precisely structured collections spanning **Men**, **Women**, **Kids**, and **Accessories** featuring authentic Indian apparel (Kasavu dhotis, Kanchipuram silks, Anarkalis, Sherwanis, Kurta pyjamas, and ethnic jewelry).
* **Interactive Shopping Bag**: Real-time cart management allowing users to add items, update quantities, and remove products seamlessly.
* **User Authentication & Profiles**: Secure user registration, login, logout, and address management for checkout simulation.
* **Dynamic Search & Filtering**: Instant category switching and keyword search capabilities.
